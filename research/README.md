# Research notes — archival

Working notes from the reverse engineering, kept because they carry
line-cited evidence (file, byte offset, count) that the conclusions came
from. **They are not maintained.** Where a note disagrees with
[`docs/FORMAT.md`](../docs/FORMAT.md) or the code, the note lost — FORMAT.md
is the measured spec, the test suite is the proof, and
[`docs/BLOCKERS.md`](../docs/BLOCKERS.md) tracks what is still open.

Start with FORMAT.md. Come here only when you need to know *how* a
specific claim was established.
